# Code of Conduct

This project aims to be practical, direct, and respectful.

Expected behavior:

- focus on the technical issue
- assume good faith while asking for concrete evidence
- keep review comments specific and actionable
- respect maintainers' security and scope decisions
- avoid harassment, insults, threats, or personal attacks

Unacceptable behavior may result in blocked participation. Maintainers may edit,
hide, or remove comments that derail technical work or expose sensitive data.

For moderation concerns, contact the project maintainers through the private
channel listed on the GitHub repository.
